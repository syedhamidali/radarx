- **ADD:** Results of the `radarx.retrieve` and `radarx.grid` functions carry the attributes `radarx_method`, `radarx_references` (DOIs, separated by a space) and `radarx_version`, and a `history` line per call, so the papers behind a result travel with the file. `radarx.cite` returns the citations of radarx and of the methods used, as text or BibTeX, `radarx.methods` describes what a function is based on, and the new page "How to cite" lists the methods and references.
