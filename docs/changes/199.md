- **DOC:** The end-to-end workflow notebook now shows every radarx function and accessor method in a worked example: `Radar_Workflow` gains the sounding utilities, wind-profile parameters, VAD profile, Bayesian DSD retrieval, other gridding and plotting functions, radar bias and evaporation, and the new `Radar_Workflow_Advanced` covers the radar equation and unit helpers, disdrometers, raindrop trajectories, surface stations and cold pools, lightning, tornado detection and biological echo, single-Doppler winds, the diabatic Lagrangian analysis and the machine-learning interface. A function index lists every name with its section, and a test fails when a new function is not shown. The two machine-learning notebooks now train on real data: `ML_KDP` fits a linear network to the KDP of the CSAPR2 processor on some azimuth sectors and tests it on others, and `ML_Single_Doppler` fits one to the KGWX and KBMX dual-Doppler wind on two volume pairs and tests it on a later one. The PERiLS PIPS prior and its data README cite the archive data set (Dawson et al. 2025) and the campaign paper (Kosiba et al. 2024), and the examples use the generic prior by default.
