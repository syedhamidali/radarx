- **ADD:** ``radarx.io.sounding``: observed soundings (Iowa Environmental Mesonet, University of Wyoming, IGRA2; local CSV, SHARPpy/SPC, UWyo, IGRA2 and IEM files) and ERA5 profiles (ECMWF ARCO time series and full ERA5 via the Copernicus CDS, or Google's anonymous ARCO-ERA5 Zarr store; by default hourly ERA5 on 37 levels from the CDS with a CDS key, otherwise from Google's ARCO-ERA5) in one xarray format on ``height``, nearest-station lookup, interpolation to gate, QVP or grid heights, 0/−10/−20 °C and wet-bulb 0 °C heights, layer-mean winds, Bolton (1980) thermodynamics, ERA5 or sounding backgrounds on radarx grids (winds rotated to the grid axes, air density, freezing level) and the accessors ``dtree.radarx.sounding()``, ``ds.radarx.interpolate_profile()`` and ``grid.radarx.background()``. The numerical work runs in a multithreaded C++ kernel with a NumPy fallback. Install the ERA5 readers with ``pip install radarx[sounding]``.
