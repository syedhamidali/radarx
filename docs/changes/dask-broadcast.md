- **ENH:** Keep dask arrays lazy in the retrieval functions. `echo_mask`, `apply_mask`, `estimate_kdp`, `llsd` (`azimuthal_shear`, `radial_divergence`), `dealias_velocity`, `dealias_confidence`, `correct_dual_prf`, `hid`, `dsd`, `qvp` and the column products `vil`, `vil_density` and `echo_top` of a grid or profile return dask arrays for dask input instead of loading the data, with one shared mechanism (`radarx/_sweepwise.py`) that runs the kernel on each chunk. The functions that need a whole volume or all times (gridding, wind retrievals, motion, hail, profiles of several volumes) compute dask input explicitly, and the Notes of every function and the "Dask and extra dimensions" section of the usage page say which function is which.
