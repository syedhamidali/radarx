- **MNT:** radarx uses the released xradar 0.13 instead of xradar `main`. The conda environments of the docs and notebook builds install `xradar>=0.13` from conda-forge, the minimum in `requirements.txt` and the unit-test environments is xradar 0.13 and xarray 2026.7 (xradar 0.13 needs 2026.4, whose time decoding fails on the Zarr and NetCDF round trips of the tests), and `combine_nexrad_sweeps` aligns sweeps with `xradar.util.reindex_range`. The deprecated IMD reader stays for this release and is removed in the next ({issue}`91`, {issue}`92`). ({pull}`348`) by [@syedhamidali](https://github.com/syedhamidali)
