- **ADD:** `superobs` bins the gates of one or more radars into columns of a model grid (or boxes of a given size) and layers of height and returns super-observations of reflectivity and radial velocity with the radial unit vector, the number of gates, the spread, an error estimate and a flag for boxes without echo, with a compiled multithreaded kernel (Alpert and Kumar 2007); `write_wrfda_radar` writes them as a WRFDA `ob.radar` file; the new notebook `Superobs_Data_Assimilation` shows them on KGWX data.
